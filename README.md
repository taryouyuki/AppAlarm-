# アプリ起動アラーム (AppAlarm) for Android

指定した時刻になると「このアプリを開きますか？」と確認通知または全画面アラームを出し、ワンタップで目的のアプリを開く Android アプリケーションです。

## 今回の機能改善

1. **クイック設定タイル／ウィジェット拡張**
   - **クイック設定タイル (`AlarmTileService`)**: 通知パネル（クイック設定パネル）にタイルを追加可能。次のアラーム時刻とアプリ名を確認し、タップ1回で即座にON/OFFを切り替えられます。
   - **ホーム画面ウィジェット (`WidgetProvider`)**: ホーム画面から次のアラームを確認できるだけでなく、ウィジェット上の「ON / OFF」ボタンでアプリを開くことなく即座に有効/無効を切り替えられます。

2. **音量フェードイン (`WakeActivity` & 設定)**
   - アラーム鳴動時、小さい音量から滑らかにフェードインして徐々に大きくなります。
   - 設定画面から「フェードインを有効にする」のON/OFFおよびフェード秒数（5秒 / 10秒 / 20秒 / 30秒）を変更できます。

3. **履歴・統計・二度寝分析 (`HistoryActivity` & 設定)**
   - アラームの「停止」「スヌーズ」「自動起動」「通知」のアクション履歴を記録。
   - 発火回数やスヌーズ回数の統計集計に加え、スヌーズ回数の多いアラーム（寝坊注意アラーム）を自動分析して表示。
   - 設定画面で「履歴を保存する」のON/OFF切り替えに対応（履歴を残さないプライバシー設定も可能）。

4. **グループ／タグ整理 (`MainActivity` & `EditActivity`)**
   - 「朝」「仕事」「夜」「休日」などのタグ・グループをアラームごとに設定可能。
   - メイン画面上部のチップ（タグバー）でワンタップ絞り込み表示ができます。

5. **GitHubでの自動ビルド (GitHub Actions)**
   - リポジトリにプッシュすると、`.github/workflows/build.yml` により自動で Gradle ビルドが走り、インストール可能な APK（`AppAlarm-debug-apk`）が生成されます。

---

## GitHubでのビルドとインストール手順

1. 本リポジトリの変更を GitHub の `main` または `master` ブランチにプッシュします。
2. GitHub リポジトリの **Actions** タブを開きます。
3. **Build Android APK** ワークフローの実行完了後、**Artifacts** から `AppAlarm-debug-apk`（ZIP）をダウンロードします。
4. 解凍して得られる `app-debug.apk` を Android スマートフォンに転送（またはスマホのブラウザでダウンロード）してインストールします。
   - バージョンコードが更新（`versionCode 2`, `versionName "1.1"`）されているため、既存のインストール済みアプリをそのまま上書き更新できます。

---

## ローカルでのビルド方法 (Android Studio / Gradle)

```bash
# Debug APK のビルド
./gradlew assembleDebug

# 生成される APK: app/build/outputs/apk/debug/app-debug.apk
```
